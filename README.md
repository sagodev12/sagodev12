# Hola, soy Sergio 👋

**Desarrollador Backend** en Bogotá, Colombia · Python · Django REST Framework · PostgreSQL · Agentes de IA

Ingeniero de Sistemas. Construyo APIs REST y lógica de negocio con Python, Django y PostgreSQL, y llevo la IA a productos reales con agentes basados en LLMs y automatizaciones con n8n.

## Lo que he hecho

- Desarrollé el módulo financiero de una plataforma SaaS multiempresa: contabilidad NIIF, facturación, tesorería, motor de impuestos colombianos e integración con el RNDC.
- Integré agentes de IA con LLMs (ChatGPT, Claude), incluidos agentes de voz y video en tiempo real con LiveKit.
- Trabajo PostgreSQL a fondo: modelado de datos, optimización de consultas, migraciones masivas y Row Level Security.
